# Recipe Management Web Application

## Overview

A responsive web application that allows users to create, view, edit and manage recipes.

## Features

* View recipes
* Add recipes
* Edit recipes
* Store recipe information
* Interactive modal interfaces
* Persistent browser storage

## Technologies

* HTML5
* CSS3
* JavaScript
* Browser localStorage

## Technical Concepts

* DOM manipulation
* Event handling
* Local storage
* Dynamic content rendering
* Responsive web design

## What I Learned

This project strengthened my understanding of JavaScript, DOM manipulation, browser storage and building interactive user interfaces.
